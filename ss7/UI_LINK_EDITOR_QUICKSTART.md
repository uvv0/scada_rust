## Быстрый сценарий

1. Выберите КПЗ.
2. Откройте `UI Link Editor`.
3. Выберите шаблон в `Template`.
4. При необходимости нажмите `Link to KPZ`.
5. Заполните `Code` / `Title` / `Description`.
6. Нажмите `Create window from template`.
7. При необходимости доработайте окно и нажмите `Save all`.

## Редактирование готового окна

1. Выберите окно в `Окно KPZ`.
2. При необходимости измените `Code` / `Title` / `Description`.
3. Нажмите `Save window`.
4. Для layout/bindings используйте `Save all`.

## Прямое редактирование шаблона окна

1. Включите `Template editor mode`.
2. Выберите шаблон в списке или нажмите `New template` (очистит форму).
3. Заполните `Code` / `Title` / `Description` (описание можно писать в несколько строк).
4. Нажмите `Save template` — сохранятся метаданные.
5. Настройте группы, регистры и bindings (layout).
6. Нажмите `Save all` — сохранятся привязки и layout шаблона.

## Просмотр окон без редактора

1. Выберите КПЗ в верхней панели.
2. Нажмите «Просмотр окон КП».
3. При пустом списке нажмите «Reload windows».
4. Выберите окно в списке, при необходимости нажмите «Сосчитать».

## Тип компонента (SCADA)

В колонке Bindings у каждой привязки можно выбрать тип отображения: auto, led, numeric, **bar**, gauge, setpoint, button. Для типа **bar** в Preview рисуется шкала 0–100 %. Подробнее — `SCADA_COMPONENTS.md`.

## Что убрано из основного сценария

- Новое окно больше не создается вручную через пустую форму.
- Создание окна идет только через `Create window from template`.
- Работа с шаблоном окна вынесена в `Template editor mode`.
