# UI Link Editor

## Основной сценарий

В обычном режиме новое окно создается только из шаблона:

1. Выберите КПЗ.
2. Откройте `UI Link Editor`.
3. Выберите шаблон в `Template`.
4. При необходимости нажмите `Link to KPZ`.
5. Заполните `Code` / `Title` / `Description`.
6. Нажмите `Create window from template`.
7. После создания окна при необходимости измените layout и нажмите `Save all`.

## Редактирование окна

- `Окно KPZ` показывает уже созданные окна текущего КПЗ.
- `Save window` обновляет метаданные существующего окна.
- `Delete window` удаляет выбранное окно вместе с bindings и text items.
- `Reload windows` обновляет список окон.

Пустое окно вручную больше не создается. Для нового окна используется только `Create window from template`.

## Работа с шаблонами

- `Template` выбирает шаблон.
- `Link to KPZ` и `Unlink from KPZ` управляют связью шаблона с текущим КПЗ.
- `Reload templates` обновляет список шаблонов.
- `Reload links` обновляет список привязанных к КПЗ шаблонов.
- `Create window from template` создает окно и копирует в него layout шаблона.

## Template Editor Mode (редактирование шаблона окна)

`Template editor mode` переключает редактор в прямое редактирование шаблонов окон:

1. Включите режим (переключатель «Template editor mode»).
2. Выберите существующий шаблон в выпадающем списке или нажмите `New template` для новой формы.
3. Заполните `Code` / `Title` / `Description` (Description — многострочное поле).
4. Нажмите `Save template` — сохраняются метаданные шаблона в БД.
5. В колонках Groups / Available regs / Bindings настройте состав и layout.
6. Нажмите `Save all` — сохраняются привязки и layout выбранного шаблона.

Удобство:

- **Save template** — только метаданные (Code, Title, Description). Кнопка всегда доступна при выбранном или только что созданном шаблоне.
- **Save all** — привязки и расположение элементов. Доступна, когда выбран шаблон (после Save template для нового шаблона). Подсказка при наведении на кнопку уточняет действие.
- **New template** — очищает форму и сбрасывает выбор; для нового шаблона затем снова Save template и при необходимости Save all.
- В режиме шаблона поле Description многострочное для длинных описаний.

## Просмотр окон КП

Окно «Просмотр окон КП» открывается кнопкой в верхней панели (без открытия основного «Шаблон окна»):

1. Выберите КПЗ в верхней панели приложения.
2. Нажмите «Просмотр окон КП».
3. Если список пуст — нажмите «Reload windows»; при невыбранном КПЗ отображается подсказка «Сначала выберите КПЗ…».
4. Выберите окно в выпадающем списке «Окно КП:» — загрузятся привязки.
5. Нажмите «Сосчитать» для опроса регистров по Modbus. Доступны TX/RX для трассировки.

## Layout и bindings

- `Groups` задают набор групп.
- `Reload regs by groups` загружает регистры для выбранных групп.
- `Available regs` позволяет выбрать регистры для layout.
- `Bindings` показывает состав окна или шаблона. Для каждой привязки (кроме текстовых) в выпадающем списке задаётся **тип компонента**: auto, led, numeric, bar, gauge, setpoint, button (см. `SCADA_COMPONENTS.md`). Тип сохраняется в БД вместе с окном/шаблоном.
- `Save all` сохраняет layout текущей сущности:
  - окна в обычном режиме;
  - шаблона в `Template editor mode`.

## Сообщения

- `Select KPZ first` - не выбран КПЗ.
- `Select template first` - не выбран шаблон.
- `Select/save window first` - не выбрано или не создано окно.
- `Select/save template first` - не выбран или не сохранен шаблон.
- `window code/title are required` - не заполнены поля окна.
- `template code/title are required` - не заполнены поля шаблона.
- `io task already in progress` - дождитесь завершения фоновой операции.
