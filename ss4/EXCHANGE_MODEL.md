# Модель обмена (кратко)

## Транспорт
- UDP-транспорт с корреляцией ответов (`packet_id`).
- Modbus RTU payload упаковывается и распаковывается вместе с protocol headers.

## A-mode
1. Построить read blocks из включенных групп регистров.
2. Сгруппировать запросы в UDP frames.
3. Декодировать ответы и записать архивные строки (`arx_val`).
4. Записать трассу обмена в `elam`.

## Script-mode
1. Выполнить `pre`-скрипт, чтобы сформировать reads/writes.
2. Выполнить Modbus-обмен.
3. Выполнить `post`-скрипт, чтобы получить outputs/events.
4. Записать values/events и обновить runtime state.

## Надежность
- Обработка таймаутов и очистка корреляции.
- Обработка частичных ответов с warnings.
- Сбои worker не останавливают всю очередь планировщика.
