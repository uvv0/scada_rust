# Шаблон промпта сессии

Рабочая папка: `C:\andr\my2\ss4`

## Контекст
- Rust backend poller/scheduler.
- Фокус: стабильность scheduler, корректность UDP/Modbus, путь записи в БД.
- DB-интеграционные тесты требуют `TEST_DB_URL` и по умолчанию игнорируются.

## Типовой блок задачи
1. Проанализировать текущие пробелы в тестах.
2. Реализовать самый приоритетный fix или test.
3. Запустить `cargo test`.
4. Обновить `test_report.md` конкретными результатами.

## Ограничения
- Сохранять текущие тесты зелеными.
- Не откатывать несвязанные изменения пользователя.
- Делать точечные, удобные для review изменения.
