# Заметки по авариям (ss4)

## Назначение
Описать поток обработки аварий для значений опроса и записи состояния/событий аварий.

## Runtime-поток
1. Прочитать значение из цикла опроса.
2. Найти правила аварий по `(kpz_id, reg_id)`.
3. Вычислить переход active/inactive с учетом hysteresis.
4. Выполнить upsert в `alarm_state`.
5. Вставить `alarm_event` при переходах.

## Поля данных
- `rule_id`
- `kpz_id`
- `reg_id`
- `event` (`on` / `off`)
- `value`
- `set_lo`, `set_hi`, `hyst`
- `severity`
- `message`

## Операционные проверки
- Проверить, что правила аварий включены.
- Убедиться, что события не дублируются для одного и того же перехода.
- Следить за error-rate и timeout-rate планировщика, чтобы видеть задержку аварий.
