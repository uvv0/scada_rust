Нужно доработать рабочий проект `E:\v3s\sunxi-jtag-master\iar\` для UART0 V3s.

Требования:

- В проекте есть `E:\v3s\sunxi-jtag-master\src\main_init.c` с вызовом:

```c
printf("Init done\n");
```

но текста в COM-порту нет.

- Причина: в `E:\v3s\sunxi-jtag-master\src\mock.h` `printf` заменён на `__no_operation()`. Убрать эту заглушку только для `printf` либо не использовать `printf`, а реализовать вывод через UART0.

- Настроить UART0 Allwinner V3s:
  - база UART0: `0x01C28000`;
  - TX: `PB8`, RX: `PB9`;
  - pinmux function: `3`;
  - UART clock/reset: bit 16 в `BUS_CLK_GATING_REG3` (`CCM + 0x6C`) и `BUS_SOFT_RST_REG4` (`CCM + 0x2D8`);
  - параметры: `115200, 8N1`, APB clock `24 MHz`;
  - LSR: Data Ready bit 0, THR Empty bit 5.

- Реализовать минимальные функции:
  - `uart0_init()`;
  - `uart0_putc(char c)` с ожиданием `LSR & (1 << 5)`;
  - `uart0_puts(const char *)`, преобразуя `\n` в `\r\n`;
  - `uart0_getc_nonblocking()` — возвращает `-1`, если `LSR & 1` не установлен;
  - простой echo-тест: принятый из COM-порта символ отправляется обратно.

- В `main_init.c` после инициализации UART вызвать:

```c
uart0_puts("Init done\r\n");
uart0_puts("UART echo ready\r\n");
```

и в бесконечном цикле эхоировать принятые символы.

- Добавить новый `.c/.h` файл в IAR-проект `sunxi-jtag.ewp` (или `sunxi-jtag-94.ewp`, который фактически используется).

- Собрать IAR-проект без ошибок.

Проверка: в COM6, `115200 8N1`, после запуска должны появиться:

```text
Init done
UART echo ready
```

Каждый введённый символ должен немедленно возвращаться в терминал.
