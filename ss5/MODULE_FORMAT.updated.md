# Формат XIP-модулей W25Q128

## Карта памяти

Первые 20 секторов W25Q128 отведены под модули:

- физические смещения: `0x000000..0x013FFF`;
- размер слота: 4096 байт;
- физическое смещение слота `N`: `N * 0x1000`;
- адрес исполнения слота `N`: `0x90000000 + N * 0x1000`;
- Holding FlashDB: `0x014000..0x053FFF`;
- архивы FlashDB: `0x054000..0xFFFFFF`.

Модуль не копируется в RAM. STM32H750 исполняет его непосредственно из
memory-mapped окна аппаратного QUADSPI.

## Заголовок

Заголовок всегда занимает первые 10 байт:

```c
#pragma pack(push, 1)
typedef struct
{
    u16 crc;   /* CRC16 Modbus байтов от поля addr до конца тела. */
    u16 addr;  /* Смещение точки входа от начала слота; 0xFFFF = пусто. */
    u16 size;  /* Размер тела; 0 = до конца 4-КБ слота. */
    u16 type;  /* Тип модуля. */
    u16 num;   /* Номер/версия модуля. */
} qspi_module_hdr_t;
#pragma pack(pop)
```

В примере IAR `addr=12`: после 10-байтного заголовка оставлены два байта
выравнивания, а `module_entry` находится по адресу `slot_base + 0x0C`.
Значение `addr` берётся из заголовка, поэтому для другого модуля допустимо
другое смещение в пределах слота.

CRC16 Modbus начинается со значения `0xFFFF` и рассчитывается по байтам
с позиции 2 (поле `addr`) до `addr + size`. Промежуток между заголовком
и телом также входит в CRC. Если `size=0`, расчёт идёт до конца 4096-байтного
слота, а отсутствующий хвост считается заполненным `0xFF`.

При передаче файла разрешено оставить `crc=0`: загрузчик вычислит CRC,
повторно проверит весь принятый блок перед записью и запишет готовый CRC
в первые два байта Flash.

## Запуск

```c
module_manager_init();                     /* Создать менеджер. */
module_validate(slot);                     /* Проверить заголовок и CRC. */
module_start_slot(slot);                   /* Запустить поток из QSPI/XIP. */
module_stop_slot(slot);                    /* Удалить поток модуля. */
module_load_slot_buf(slot, data, length);  /* Записать без запуска. */
module_update_from_buf(slot, data, length);/* Стоп, запись, запуск. */
```

Точка входа имеет вид:

```c
void module_entry(void);
```

Каждый слот нужно линковать для его реального XIP-адреса. Модуль слота 3
с `addr=12` имеет точку входа `0x9000300C`.

## Синхронизация с FlashDB

W25Q128 одновременно содержит код модулей, Holding и архивы. Во время
стирания или программирования аппаратный QSPI не может оставаться в режиме
исполнения из `0x90000000`.

Драйвер `w25q128_fal.c` выполняет операцию атомарно:

1. захватывает общий mutex W25Q128 — остальные операции FlashDB ждут;
2. запрещает переключение задач RT-Thread;
3. выходит из memory-mapped режима;
4. стирает или программирует Flash;
5. возвращает memory-mapped режим;
6. инвалидирует D-cache изменённого диапазона и весь I-cache;
7. снова разрешает переключение задач;
8. освобождает mutex.

Прерывания и системный тик во время операции продолжают работать, но
обработчик прерывания не должен находиться в XIP-модуле. Модуль также
не должен напрямую обращаться к FlashDB: он передаёт запрос основной
прошивке через сервисную API-таблицу.

Если изменяется слот уже работающего модуля, его поток сначала удаляется.
После простой записи `module_load_slot_buf()` он остаётся остановленным.

## Загрузка через Modbus Holding

Полная процедура заполнения буфера через ELAM, разбиение файла на запросы,
проверка token, запись и обработка ошибок описаны в
`MODULE_UPLOAD_ELAM.md`.

Функция 03 читает, а функции 06/16 записывают окно:

| Holding | Назначение |
|---:|---|
| `10000..12047` | 4096 байт файла, старший байт слова первым |
| `12048` | слот `0..19` |
| `12049` | длина файла `10..4096` |
| `12050` | команда |
| `12051` | состояние |
| `12052` | код результата `MODULE_*` |
| `12053` | вычисленный CRC16 |
| `12054` | одноразовый проверочный token |
| `12055` | подтверждение token перед записью |

Безопасная последовательность:

1. Передать блок и задать слот/длину.
2. Записать `0xA501` в `12050`.
3. Дождаться `12051=2`, `12052=0`.
4. Скопировать `12054` в `12055`.
5. Записать `0xA502` в `12050`.
6. Дождаться `12051=4`, `12052=0`.

Результат также отображается в TIT функцией 04:
`2450` — состояние, `2451` — результат, `2452` — CRC,
`2453` — слот, `2454` — длина.
